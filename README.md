# Radary

Мониторинг чатов Telegram по ключевым словам с уведомлениями и управлением через бота.

Как это работает:

- **Аккаунт-наблюдатель** (Telethon) заходит под вашим личным Telegram-аккаунтом и читает
  чаты, которые вы укажете. Он должен уже состоять в этих чатах.
- Каждое входящее сообщение проверяется: сначала на **стоп-слова** (если найдено — сообщение
  игнорируется), затем на **ключевые слова** (если найдено — сообщение пересылается).
- Уведомления и всё управление (список чатов, ключевые/стоп-слова, вкл/выкл мониторинга,
  импорт/экспорт настроек) происходят через отдельного **Telegram-бота** (aiogram) с кнопками.
  Интерфейса вне Telegram нет.

## Требования

- Python 3.11+
- Личный Telegram-аккаунт, который будет читать чаты (`api_id`/`api_hash` с
  https://my.telegram.org/apps)
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather) (нужен `BOT_TOKEN`)
- Сервер или ПК, который будет работать круглосуточно (пока он выключен — мониторинг не идёт)

## Установка

```bash
git clone <repo>
cd radary-
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

- `API_ID`, `API_HASH` — с https://my.telegram.org/apps
- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_IDS` — ваш Telegram ID (можно узнать у [@userinfobot](https://t.me/userinfobot)),
  через запятую можно указать несколько
- `SESSION_NAME`, `CONFIG_PATH` — можно оставить по умолчанию

### Первый вход в аккаунт-наблюдатель (один раз)

```bash
python scripts/login.py
```

Скрипт спросит номер телефона, код из Telegram и, если включена, 2FA-пароль. После этого
рядом появится `.session`-файл — он даёт полный доступ к аккаунту, никому его не передавайте
и не публикуйте в git (он уже в `.gitignore`).

### Запуск

```bash
python run.py
```

Откройте своего бота в Telegram и отправьте `/start` — появится меню с кнопками.

## Управление через бота

- **▶️/⏸ Мониторинг** — включить/выключить проверку сообщений
- **💬 Чаты** — список отслеживаемых чатов, добавление по `@username`, ID или ссылке
  `t.me/...` (аккаунт-наблюдатель должен уже состоять в чате), удаление по кнопке
- **🔑 Ключевые слова** / **🚫 Стоп-слова** — добавление списком (каждое слово с новой строки),
  удаление по кнопке, полная очистка
- **📄 Экспорт конфига** — бот присылает текущий `config.json`
- **📥 Импорт конфига** — отправьте боту файл `config.json` (см. формат ниже), он полностью
  заменит текущие настройки чатов/слов
- **ℹ️ Статус** — состояние мониторинга и авторизации аккаунта-наблюдателя

Управлять ботом могут только пользователи, чьи ID перечислены в `ADMIN_IDS`.

## Формат config.json

```json
{
  "chats": [
    {"id": -1001234567890, "title": "Название чата", "username": "chat_username"}
  ],
  "keywords": ["купить", "продам", "срочно"],
  "stop_words": ["реклама"],
  "monitoring_enabled": true
}
```

Пример лежит в `data/config.example.json`. Сравнение слов — по вхождению подстроки,
без учёта регистра.

## Круглосуточная работа

Скрипт должен работать непрерывно на сервере или ПК, который не выключается.

### Вариант 1 — systemd (Linux-сервер)

```ini
# /etc/systemd/system/radary.service
[Unit]
Description=Radary keyword monitor
After=network.target

[Service]
WorkingDirectory=/opt/radary
ExecStart=/opt/radary/.venv/bin/python run.py
Restart=always
RestartSec=5
EnvironmentFile=/opt/radary/.env

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now radary
```

### Вариант 2 — Docker

```bash
python scripts/login.py   # session-файл создаётся до старта контейнера
docker compose up -d --build
```

`data/` монтируется как volume, так что конфиг и сессия сохраняются между перезапусками.

## Важно про безопасность и ограничения

- `.session`-файл и `.env` дают полный доступ к вашему Telegram-аккаунту и боту — не
  публикуйте их и не передавайте третьим лицам.
- Аккаунт-наблюдатель может мониторить только те чаты, в которых он уже состоит — это
  ограничение самого Telegram, а не бота.
- Слишком частое добавление/чтение множества чатов одним аккаунтом может привести к
  временным ограничениям от Telegram — используйте разумное количество чатов.
